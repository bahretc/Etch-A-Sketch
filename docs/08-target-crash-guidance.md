# 08 - Target Crash Type Guidance (Intersection Treatments)

Transcribed from the workbook guidance sheet. This drives the target definition module. Frontal impact crash types are officially: left-turn same roadway (LTSR), left-turn different roadway (LTDR), right-turn same roadway (RTSR), right-turn different roadway (RTDR), head-on, and angle.

| Countermeasure | Target-1 | Target-2 | Notes |
|---|---|---|---|
| Advance Activated Warning Sign (Be Prepared to Stop) | Frontal impacts where vehicle on treated approach ran red light | Rear ends approaching intersection on treated approaches | Treated approaches are likely both mainline approaches |
| All Way Stop | Frontal impacts in intersection | - | - |
| Reduced Conflict Intersection (RCI) | Frontal impacts involving a vehicle making a movement restricted in the after period | - | If U-turn bulbouts were constructed, the whole constructed section may need inclusion; if RCI only, analyze downstream U-turn crashes in a separate table |
| Flashing Traffic Signal (overhead non-actuated flasher) | Frontal impacts in intersection | - | - |
| Grade Separation | Frontal impacts in intersection | - | - |
| Increase Conspicuity of Stop Condition (double indicated stop, transverse rumble strips, double arrow) | Frontal impacts where vehicle on treated approach ran the stop sign | - | Include Ran Off Road - Straight crashes for T intersections |
| Increase Conspicuity of Traffic Signal (double indicated red, backplates) | Frontal impacts where vehicle on treated approach ran red light | - | Include rear ends from treated approaches in the Additional Information table |
| Intersection Realignment | Frontal impacts in intersection | Varies by treatment (rear end or lane departure) | Y-lines may need extension; analyze the entire impacted area |
| Left Turn Lane - New Installation | Rear ends approaching intersection on treated approaches | LTSR on treated approaches | On multilane facilities, rear ends may need to be inner-lane specific |
| Left Turn Lane - Offset Existing | LTSR on treated approaches | - | - |
| Median Channelization on an Approach (access management) | Frontal impacts involving a vehicle making a restricted movement | Varies (e.g. rear ends alleviated by the restriction) | Analyze a potential area of influence / downstream U-turn crashes |
| New Traffic Signal | Frontal impacts in intersection | - | - |
| Pedestrian/Bicycle Treatments | Pedestrian and bicycle crashes | - | For a pedestrian signal, rear ends may also need analysis |
| Remove Access/Intersection | Frontal impacts in intersection (varies with what was removed) | Varies (e.g. rear ends) | - |
| Right Turn Lane at Intersection | Rear ends approaching intersection on treated approaches | Sideswipes approaching intersection on treated approaches | On multilane facilities, may need to be outer-lane specific |
| Roundabout | Frontal impacts in intersection | - | For rural roundabouts note lighting presence and any nighttime crash or nighttime lane departure patterns in the additional info table and/or discussion |
| Sight Distance Improvements | Frontal impacts in intersection | - | May limit to maneuvers directly affected (e.g. one cleared quadrant) |
| Traffic Signal Revisions - Flashing Yellow Arrow | LTSR on treated approaches | - | - |
| Traffic Signal Revisions - Left Turn Phasing | LTSR on treated approaches | - | - |
| Vehicle Entering When Flashing (VEWF) | Frontal impacts involving vehicles from treated approaches | - | Determine treated approaches from sign and loop placement; signs on one approach means only that approach's crashes count. Same-roadway crashes (LTSR, RTSR, head-on) are excluded since flashers are not visible to same-roadway traffic |

Observed applied VEWF definition (SS-6002AS): frontal impact crashes involving vehicles from BOTH the major road and the side roads (Angle, LTDR, RTDR); frontal impacts involving only major-road vehicles or only side-road vehicles are not included.
